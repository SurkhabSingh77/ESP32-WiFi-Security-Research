# Wireless Experiment Log Template

Copy this file for each experiment and replace the prompts. Do not include private network names, passwords, MAC addresses, personal data, or third-party traffic.

## Experiment details

- **Date:**
- **Device(s):**
- **Firmware and version:**
- **Purpose / learning question:**
- **Authorization:** State that the device/network is yours or that explicit permission was obtained.
- **Test environment:** Describe the isolated or controlled setup without identifying private networks.

## Setup

Describe hardware, connections, configuration, and relevant settings. Include a wiring diagram where appropriate.

## Procedure

Record the steps at a high level so the experiment can be repeated safely. Avoid publishing instructions for disrupting or accessing networks without authorization.

## Observations

Record what the device displayed or measured. Separate direct observations from assumptions.

## Outcome

- What worked?
- What did not work?
- What did I learn?
- What would I change in a repeat test?

## Defensive relevance

Explain any defensive lesson or configuration improvement. For router hardening, record only settings that were actually checked or changed.

## Limitations

List hardware, firmware, range, compatibility, and measurement limitations.

## Evidence

Link only to personal photos, sanitized screenshots, and non-sensitive artifacts.

## Safety and privacy check

- [ ] Experiment was performed on owned or explicitly authorized equipment/network.
- [ ] No credentials, private identifiers, or personal traffic are included.
- [ ] No third-party network data is published.
- [ ] Any potentially disruptive test was conducted in a controlled environment.
